# Sistema de carga de productos
Aplicaion de escritorio en java que sirve para registrar productos .Permite ingresar el nombre , precio y stock de un producto ,  que valida que los datos sean correctos y muestra la informacion en pantalla .Tambien tiene un boton para limpiar el formulario 
# Archivos 
Porducto.java: clase que respresenta un producto (nombre,precio,stock)
Main.java : ventana principal con el formulario y la logica de la aplicacion 
# Como ejecutar
Compilar: Main.java Producto.java
Ejecutar: Main.java
